# ⚙️ SolidWorks Mechanical Design Portfolio

This folder contains all **SolidWorks models and mechanical design projects** completed during my **SureTrust Mechanical CAD Internship**.

The projects cover everything from beginner part modelling exercises to advanced mechanical assemblies, sheet metal components, and surface modelling. These assignments helped me develop strong practical skills in 3D CAD modelling, design visualization, and engineering product development.

---

# 📂 Folder Structure

| Folder | Description |
|:--------|:------------|
| 📁 Basic Exercises | Beginner modelling exercises to develop core SolidWorks skills and feature-based modelling. |
| 📁 Part Modelling | Individual mechanical components created using parametric modelling techniques. |
| 📁 Assembly Designs | Complete mechanical assemblies with proper mates, constraints, and exploded views. |
| 📁 Advance Modelling | Complex mechanical components designed using advanced SolidWorks features. |
| 📁 Sheet Metal | Sheet metal parts and fabricated components developed using SolidWorks Sheet Metal tools. |
| 📁 Surface Modelling | Surface modelling projects demonstrating advanced freeform design techniques. |
